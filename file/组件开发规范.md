# Function-Agent 组件开发规范

本文档规范了数学可视化组件（`js/components/math/*.js`）和工具执行器（`js/tools/definitions/*.js`）的开发标准。

---

## 1. 组件分类

所有数学可视化组件按渲染引擎分为三类：

### 1.1 Plotly 图表组件

适用于静态或半交互式 2D/3D 图表。

**使用的组件：** `function-plot`、`polar-curve`、`parametric-curve`、`fourier-series`、`distribution`、`clt-animation`、`surface-3d`、`solid-revolution`、`multivariable-integral`、`sequence`、`taylor-animation`、`differential-view`、`integral-area`、`gradient-field`、`parameter-slider`

**标准模板：**

```javascript
export function render(container, props) {
  const wrapper = document.createElement('div');
  wrapper.className = 'math-component math-component-body';

  const plotDiv = document.createElement('div');
  plotDiv.className = 'plotly-container';
  plotDiv.style.height = '400px';  // 默认高度
  wrapper.appendChild(plotDiv);
  container.appendChild(wrapper);

  // 构建 Plotly 数据和布局
  const data = [...];
  const layout = {
    // 必须设置以下基础属性
    paper_bgcolor: 'transparent',
    plot_bgcolor: 'transparent',
    font: { color: 'var(--color-text-primary)' },
    margin: { t: 30, r: 20, b: 40, l: 50 },
    // 响应主题
    template: getComputedStyle(document.documentElement)
      .getPropertyValue('--color-bg-card').trim() === '#1c1c1c' ? 'plotly_dark' : undefined,
  };
  const config = { responsive: true, displayModeBar: false };

  Plotly.newPlot(plotDiv, data, layout, config);
  return wrapper;
}
```

**关键规范：**

| 规则 | 说明 |
|------|------|
| 容器类名 | 必须使用 `.plotly-container` |
| 默认高度 | 设置 `style.height = '400px'`（全屏时会被 CSS 自动拉伸） |
| 透明背景 | `paper_bgcolor: 'transparent'`，`plot_bgcolor: 'transparent'` |
| 不显示工具栏 | `displayModeBar: false`（保持界面简洁） |
| 响应式 | `responsive: true` |
| 字体颜色 | 通过 CSS 变量 `var(--color-text-primary)` 适配主题 |

### 1.2 Canvas 动画组件

适用于需要逐帧动画的实时可视化。

**使用的组件：** `limit-animation`、`matrix-transform`、`eigenvectors`、`series-convergence`

**标准模板：**

```javascript
export function render(container, props) {
  const wrapper = document.createElement('div');
  wrapper.className = 'math-component math-component-body';

  const canvasDiv = document.createElement('div');
  canvasDiv.className = 'canvas-container';
  wrapper.appendChild(canvasDiv);
  container.appendChild(wrapper);

  const canvas = document.createElement('canvas');
  canvasDiv.appendChild(canvas);

  // 设置尺寸
  function resize() {
    const w = canvasDiv.clientWidth;
    const h = canvasDiv.clientHeight || 400;
    canvas.width = w * devicePixelRatio;
    canvas.height = h * devicePixelRatio;
    canvas.style.width = w + 'px';
    canvas.style.height = h + 'px';
  }
  resize();

  // 自适应（全屏切换时）
  const observer = new ResizeObserver(resize);
  observer.observe(canvasDiv);

  // 绘制函数
  const ctx = canvas.getContext('2d');
  let animationId;

  function draw() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.scale(devicePixelRatio, devicePixelRatio);
    // ... 绘制逻辑 ...
    ctx.setTransform(1, 0, 0, 1, 0, 0);
    animationId = requestAnimationFrame(draw);
  }
  draw();

  return wrapper;
}
```

**关键规范：**

| 规则 | 说明 |
|------|------|
| 容器类名 | 必须使用 `.canvas-container` |
| ResizeObserver | **必须**使用 ResizeObserver 监听容器尺寸变化，确保全屏切换后正确重绘 |
| devicePixelRatio | 使用 DPR 缩放确保高清显示 |
| scale/reset | 每帧 `ctx.scale(dpr, dpr)` 绘制，结尾 `ctx.setTransform(1,0,0,1,0,0)` 重置 |
| 自适应坐标 | 使用 `Math.min(w,h) / N` 作为坐标比例，适配不同容器尺寸 |

### 1.3 DOM 组件

适用于不需要图表引擎的纯 HTML 交互组件。

**使用的组件：** `step-card`、`knowledge-tip`、`comparison-table`、`interactive-quiz`、`latex-renderer`

**关键规范：**

| 规则 | 说明 |
|------|------|
| 容器类名 | 外层 `math-component`，内层 `math-component-body` |
| 主题适配 | 所有颜色使用 `var(--color-*)` CSS 变量 |
| LaTeX 渲染 | 引用 `js/utils/latex.js` 的 `renderLatexHTML()` 处理公式 |
| 交互反馈 | 鼠标悬浮、点击等交互需有视觉反馈（颜色/阴影变化） |

## 2. 工具执行器规范

### 2.1 标准接口

```javascript
/**
 * 工具执行函数
 * @param {Object} args - 从 LLM tool_call.arguments 解析的参数对象
 * @returns {Object} { componentType: string, props: Object }
 * @throws {Error} 参数验证失败或计算错误时抛出异常
 */
export function execute(args) {
  // 1. 参数解构与默认值
  const { requiredParam, optionalParam = 'default' } = args;

  // 2. 参数验证（缺失必填参数时抛出异常）
  if (!requiredParam) {
    throw new Error('缺少必填参数: requiredParam');
  }

  // 3. 计算逻辑（纯数据处理，无 DOM 操作）
  const result = compute(requiredParam, optionalParam);

  // 4. 返回结果
  return {
    componentType: 'component-name',  // 对应 components/math/ 下的组件
    props: {
      // 传递给渲染器的数据
      data: result,
      config: { ... },
    },
  };
}
```

### 2.2 设计原则

| 原则 | 说明 |
|------|------|
| **纯计算** | Definition 不操作 DOM，只返回 `{ componentType, props }` |
| **参数宽容** | 合理设置默认值，对非必填参数的缺失不报错 |
| **异常抛出** | 无法处理的情况抛出 Error，由 executor 捕获转为错误状态 |
| **数据预处理** | 将原始参数转换为渲染器需要的格式（如数学表达式求值） |

## 3. 渲染器注册规范

### 3.1 math/index.js 动态导入表

```javascript
const COMPONENT_MAP = {
  'function-plot': () => import('./function-plot.js'),
  'new-component': () => import('./new-component.js'),
};

export function renderMathComponent(name, props) {
  const loader = COMPONENT_MAP[name];
  if (!loader) return null;
  return loader().then((mod) => mod.render(createContainer(), props));
}
```

## 4. 全屏适配规范

所有数学可视化组件必须正确适配全屏模式：

### 4.1 Plotly 组件

全屏后 CSS 会自动拉伸 `.plotly-container`（`flex: 1; height: 100%`）。但需要在全屏完成后触发 `Plotly.Plots.resize()`。这由 `tool-call-card.js` 在全屏切换后自动调用，**组件本身无需额外处理**。

### 4.2 Canvas 组件

**必须**使用 `ResizeObserver` 监听容器尺寸变化：

```javascript
const observer = new ResizeObserver(() => {
  resize();  // 重新设置 canvas 尺寸
  draw();    // 重绘内容
});
observer.observe(canvasDiv);
```

### 4.3 DOM 组件

确保使用 CSS 变量和 `flex` 布局，全屏后内容应自然拉伸。

## 5. 主题适配规范

### 5.1 通用规则

| 元素 | 亮色 | 暗色 | CSS 变量 |
|------|------|------|----------|
| 背景 | 白色系 | 深灰/黑色 | `var(--color-bg-card)` |
| 文字 | 深色 | 浅灰 | `var(--color-text-primary)` |
| 次要文字 | 灰色 | 中灰 | `var(--color-text-secondary)` |
| 强调色 | 蓝色 | 钢蓝 | `var(--color-accent)` |
| 边框 | 浅灰 | 深灰 | `var(--color-border)` |
| 错误 | 红色 | 浅红 | `var(--color-error)` |
| 成功 | 绿色 | 浅绿 | `var(--color-success)` |

### 5.2 Plotly 图表

通过检查 CSS 变量判断当前主题：

```javascript
const isDark = getComputedStyle(document.documentElement)
  .getPropertyValue('--color-bg-card').trim() === '#1c1c1c';
```

或直接使用 `transparent` 背景让 CSS 控制。

### 5.3 Canvas 动画

读取 CSS 变量作为绘图颜色：

```javascript
const textColor = getComputedStyle(document.documentElement)
  .getPropertyValue('--color-text-primary').trim();
ctx.fillStyle = textColor;
```

## 6. LaTeX 渲染规范

### 6.1 使用共享工具

组件中需要渲染 LaTeX 公式时，使用 `js/utils/latex.js` 的共享函数：

```javascript
import { renderLatexHTML } from '../../utils/latex.js';

// 渲染包含 LaTeX 的文本
element.innerHTML = renderLatexHTML('当 $x \\to 0$ 时，$$\\lim_{x \\to 0} \\frac{\\sin x}{x} = 1$$');
```

### 6.2 支持的语法

| 语法 | 模式 | 示例 |
|------|------|------|
| `$$...$$` | display math（块级） | `$$E=mc^2$$` |
| `\(...\)` | inline math（行内） | `\(x^2 + y^2\)` |
| `$...$` | inline math（行内） | `$f(x)$` |

## 7. 滚动穿透规范

组件内的图表/画布默认**不拦截**滚轮事件，确保页面滚动流畅。这是通过 CSS 实现的：

```css
/* message.css 中已定义 */
.tool-call-card:not(.focused) .plotly-container,
.tool-call-card:not(.focused) .canvas-container {
  pointer-events: none;
}
```

组件开发者**无需**在 JS 中处理滚轮事件拦截。

## 8. 性能规范

| 规则 | 说明 |
|------|------|
| 按需加载 | 所有数学组件通过动态 `import()` 加载，不阻塞首屏 |
| Canvas 高清 | 使用 `devicePixelRatio` 确保高清屏清晰 |
| 动画帧率 | Canvas 动画应使用 `requestAnimationFrame`，不使用 `setInterval` |
| Plotly 尊重 | 设置 `responsive: true` 让 Plotly 自动处理窗口变化 |
| 避免内存泄漏 | Canvas 动画组件应在适当时机 `cancelAnimationFrame` |
| 大数据集 | Plotly 数据点超过 10000 时考虑降采样 |
