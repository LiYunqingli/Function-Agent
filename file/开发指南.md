# Function-Agent 开发指南

---

## 1. 环境准备

### 1.1 前置条件

- 现代浏览器（Chrome 90+、Firefox 90+、Edge 90+、Safari 15+）
- 代码编辑器（推荐 VS Code）
- 本地 HTTP 服务器（用于开发调试 ES Modules）

### 1.2 启动开发服务器

由于使用了 ES Modules，不能直接以 `file://` 协议打开（部分浏览器限制），需通过 HTTP 服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# VS Code
# 安装 Live Server 扩展，右键 index.html → Open with Live Server
```

## 2. 开发规范

### 2.1 模块规范

- 所有 JS 文件使用 **ES Modules**（`import` / `export`）
- 每个文件一个导出（函数/类/单例），命名与文件名对应
- 不使用任何构建工具或打包器
- 外部依赖通过 CDN 在 `index.html` 中引入

### 2.2 命名规范

| 类别 | 规范 | 示例 |
|------|------|------|
| 文件名 | kebab-case | `tool-call-card.js` |
| CSS 类名 | kebab-case | `.tool-call-card` |
| JS 函数 | camelCase | `createToolCallCard()` |
| JS 类 | PascalCase | `ToolRegistry`, `ChatStore` |
| 常量 | UPPER_SNAKE_CASE | `MAX_TOOL_DEPTH` |
| CSS 变量 | kebab-case + 前缀 | `--color-bg-primary` |
| DOM ID | kebab-case | `message-list` |
| 工具名 | snake_case（LLM 约定） | `plot_function` |
| 组件名 | kebab-case | `function-plot` |

### 2.3 注释规范

```javascript
/**
 * 函数说明 —— 使用 JSDoc 格式
 * @param {Type} name - 参数说明
 * @returns {Type} 返回值说明
 */

// ★ 重要设计决策（用 ★ 标记）
// ★ 纯 CSS pointer-events 方案，避免 JS wheel 拦截

// ── 分隔线（用 ── 标记段落）
// ── FLIP: First ──

// 关键日志（方括号前缀）
console.log('[runAI] 启动 generation=%d', myGeneration);
```

### 2.4 样式规范

- 所有颜色、间距、字体通过 **CSS 变量** 引用（`var(--color-bg-primary)`）
- 暗色主题通过 `[data-theme="dark"]` 选择器覆盖变量值
- 组件样式写在对应的 CSS 文件中，不使用内联样式（JS 中动态设置的除外）
- 响应式通过媒体查询断点：`640px` / `1024px` / `1440px`

## 3. 新增工具组件（7 步流程）

以新增一个"绘制隐函数"工具为例：

### Step 1: 编写 Schema

在 `js/tools/schemas.js` 中添加 OpenAI Function Calling 格式的参数定义：

```javascript
// ── plot_implicit_function ──
{
  type: 'function',
  function: {
    name: 'plot_implicit_function',
    description: '绘制隐函数 f(x,y)=0 的图像',
    parameters: {
      type: 'object',
      properties: {
        expression: { type: 'string', description: '隐函数表达式，如 x^2+y^2-1' },
        xRange: { type: 'array', items: { type: 'number' }, description: 'x 范围 [min, max]' },
        yRange: { type: 'array', items: { type: 'number' }, description: 'y 范围 [min, max]' },
        resolution: { type: 'number', description: '网格分辨率', default: 100 },
      },
      required: ['expression'],
    },
  },
},
```

### Step 2: 编写执行器

创建 `js/tools/definitions/plot-implicit-function.js`：

```javascript
/**
 * 隐函数图像绘制工具
 */
export function execute(args) {
  // 参数验证
  const { expression, xRange = [-5, 5], yRange = [-5, 5], resolution = 100 } = args;

  // 执行计算逻辑
  // ... 生成等高线数据 ...

  return {
    componentType: 'implicit-function',
    props: {
      expression,
      xRange,
      yRange,
      contours: [...],  // 计算结果
    },
  };
}
```

### Step 3: 编写渲染器

创建 `js/components/math/implicit-function.js`：

```javascript
import Plotly from 'plotly.js-dist-min';  // CDN 全局变量

export function render(container, props) {
  // 创建容器
  const wrapper = document.createElement('div');
  wrapper.className = 'math-component math-component-body';

  const plotDiv = document.createElement('div');
  plotDiv.className = 'plotly-container';
  plotDiv.style.height = '400px';
  wrapper.appendChild(plotDiv);

  container.appendChild(wrapper);

  // 绘制图表
  Plotly.newPlot(plotDiv, data, layout, config);

  return wrapper;
}
```

### Step 4: 注册工具

在 `js/tools/register-all.js` 中添加注册：

```javascript
import { execute as plotImplicitFunction } from './definitions/plot-implicit-function.js';
import { plot_implicit_function as plotImplicitFunctionSchema } from './schemas.js';

registry.register(plotImplicitFunctionSchema, plotImplicitFunction);
```

### Step 5: 注册渲染器

在 `js/components/math/index.js` 中添加动态导入：

```javascript
const COMPONENT_MAP = {
  // ... 已有组件 ...
  'implicit-function': () => import('./implicit-function.js'),
};
```

### Step 6: 更新配置映射

在 `js/config.js` 中添加：

```javascript
// TOOL_COMPONENT_MAP
plot_implicit_function: 'implicit-function',

// TOOL_ICONS
plot_implicit_function: '🌀',
```

### Step 7: 更新 System Prompt

在 `js/config.js` 的 `DEFAULT_SETTINGS.systemPrompt` 中添加工具描述：

```
plot_implicit_function(隐函数图像绘制)
```

## 4. 调试技巧

### 4.1 控制台日志

项目使用统一的前缀日志格式：

| 前缀 | 来源 | 说明 |
|------|------|------|
| `[runAI]` | chat-area.js | Agent Loop 状态 |
| `[createStream]` | ai-client.js | SSE 请求/响应 |
| `[handleSend]` | chat-area.js | 消息发送 |
| `[compactMessages]` | chat-area.js | 消息压缩 |
| `[buildMessages]` | chat-area.js | API 消息构建 |

### 4.2 常见调试场景

**工具未被调用**
1. 检查 schema 是否正确注册（控制台输出 "已注册 24 个工具"）
2. 检查 systemPrompt 中是否包含工具描述
3. 检查 schema 的 `required` 字段是否正确
4. 查看 `[createStream]` 日志中的 `tools=N` 是否 > 0

**工具执行失败**
1. 查看控制台是否有异常堆栈
2. 检查 definition 中的参数验证逻辑
3. 检查返回值格式是否为 `{ componentType, props }`

**图表不显示**
1. 检查 Plotly CDN 是否加载成功（`window.Plotly`）
2. 检查容器是否挂载到 DOM
3. 检查数据格式是否符合 Plotly 要求

**全屏动画异常**
1. 检查卡片是否使用 `canvas-container` 或 `plotly-container` 类名
2. 检查 CSS 是否有 `!important` 覆盖

### 4.3 状态调试

```javascript
// 在控制台中查看当前状态
// ChatStore
window._chatStore?.getState()  // 或通过 elements 查找

// 直接查看 localStorage
localStorage.getItem('gaoshu_settings')
JSON.parse(localStorage.getItem('gaoshu_sessions'))?.length
```
