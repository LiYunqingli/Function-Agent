# Function-Agent 用户帮助文档

---

## 1. 快速开始

### 1.1 打开应用

直接用浏览器打开 `index.html` 文件即可使用，无需安装任何依赖或启动服务。所有依赖库已本地化，支持完全离线使用。

### 1.2 配置 AI 模型

首次使用需要配置大语言模型 API：

1. 点击右上角 **设置** 按钮（齿轮图标）
2. 填写以下信息：
   - **API URL**：兼容 OpenAI 格式的 API 地址（默认预填 `https://api.deepseek.com`）
   - **API Key**：你的 API 密钥
   - **模型名称**：如 `deepseek-chat`、`gpt-4o`、`gpt-4o-mini`、`qwen-plus`、`glm-4` 等
   - **Temperature**：控制回复创造性（0.0~2.0，默认 0.7）
   - **Max Tokens**：最大输出长度（默认 4096）
3. 点击保存

### 1.3 图片识别（可选）

如需识别数学题目图片，需额外配置多模态模型：
- **Vision API URL / Key / Model**：支持图片识别的模型连接信息（默认预填阿里云 dashscope）
- **Vision System Prompt**：图片识别的提示词（已预填默认值）

### 1.4 System Prompt 自定义（高级）

在设置页的"大语言模型 System Prompt"区域，Prompt 被拆分为四个可独立编辑的部分：
- **角色定义**：AI 的身份与专业领域
- **可用工具列表**：所有可调用工具及用途
- **注意事项**：回复行为规范
- **其他补充**：引导策略与互动建议

点击各部分标题可展开/折叠编辑区，点击"预览完整 Prompt"查看合并后的最终效果，点击"恢复默认"重置所有内容。

## 2. 基本操作

### 2.1 发送消息

- 在底部输入框中输入数学问题
- 按 **Enter** 发送（**Shift+Enter** 换行）
- 点击发送按钮（向右箭头）

### 2.2 数学符号键盘 ⬅ 新增

- 点击输入框上方的数学符号按钮可弹出符号键盘
- 支持快速输入希腊字母（α、β、γ…）、微积分符号（∫、∂、∞…）、矩阵符号等
- 点击符号即可插入到输入框光标位置

### 2.3 上传图片

- 点击输入框左侧的 **图片上传** 按钮
- 选择包含数学题目的图片
- 输入你想问的问题（可选，不输入则自动分析图片内容）
- 发送后系统会先识别图片，再基于识别结果回答

### 2.4 停止生成

在 AI 回复过程中，点击 **停止** 按钮（红色方块）可中断当前生成。

### 2.5 切换主题

点击右上角的 **月亮/太阳** 图标，在三种主题间切换：
- **亮色模式**
- **暗色模式**
- **跟随系统**

## 3. 会话管理

### 3.1 新建会话

- 点击侧边栏顶部的 **新建对话** 按钮
- 或在欢迎页点击 **开始新对话**

### 3.2 切换会话

点击侧边栏中的会话列表即可切换到对应对话。每个会话的历史消息独立保存。

### 3.3 删除会话

将鼠标悬停在侧边栏的会话上，点击出现的 **删除** 按钮（垃圾桶图标）即可删除。

### 3.4 会话命名

可在设置中选择两种命名方式：
- **首句截取命名**：取第一条消息的前 N 个字符（默认 15 字）
- **AI 自动命名**：由 LLM 根据对话内容自动生成标题

---

## 4. 收藏夹 ⬅ 新增

### 4.1 收藏消息

- **右键点击**任意消息或工具卡片，弹出自定义右键菜单
- 选择"收藏选中文本"收藏选中的文字
- 选择"收藏全部回复"收藏整条 AI 回复

### 4.2 管理收藏

- 点击顶栏的 **⭐ 收藏夹** 按钮打开收藏面板
- 收藏条目按时间倒序排列
- 点击收藏项可跳转到对应的会话和消息位置
- **双击标题**可重命名收藏条目
- 点击删除按钮移除收藏

### 4.3 收藏命名

可在设置中选择命名方式：
- **首句截取命名**：取收藏内容的开头字符
- **AI 自动命名**：由 LLM 根据收藏内容生成标题

## 5. 学习统计 ⬅ 新增

- 点击顶栏的 **统计** 按钮（柱状图图标）打开学习统计面板
- 查看总 Token 用量（输入/输出）
- 查看按数学分支分类的工具使用分布：
  - 微积分（函数图像、极限、微分、积分、级数、极坐标…）
  - 线性代数（矩阵变换、特征向量）
  - 概率统计（概率分布、中心极限定理）
  - 解题技巧（步骤卡、知识点提示）
  - 互动测验、对比分析等
- 查看总会话数量和消息数量

## 6. 工具调用卡片

当 AI 调用工具时，会在对话中显示一个 **工具调用卡片**，包含：

### 6.1 卡片结构

| 区域 | 内容 |
|------|------|
| **Header** | 工具名称 + 状态徽章（执行中/已完成/失败）+ 全屏按钮 |
| **参数折叠区** | 可展开查看发送给工具的完整参数（JSON 格式） |
| **结果区域** | 工具生成的可视化内容（图表/动画/交互组件） |

### 6.2 全屏查看

- 点击 Header 右侧的 **⛶** 按钮进入全屏
- 或 **双击** 卡片进入全屏
- 全屏后：
  - 按 **ESC** 退出
  - 点击 **右上角关闭按钮** 退出
  - 点击 **背景遮罩** 退出

### 6.3 图表交互

- **默认**：鼠标悬浮在图表上时，滚轮事件穿透到页面（正常滚动）
- **点击图表区域** 后激活焦点（边框高亮），此时可：
  - 拖动平移图表
  - 滚轮缩放图表
  - 悬浮查看数据点
- **鼠标移出卡片** 后自动失焦，恢复滚轮穿透

### 6.4 折叠/展开

点击卡片 Header 区域可折叠/展开结果内容，方便管理长对话。

## 8. 使用技巧

### 8.1 如何获得最佳效果

1. **明确描述需求**：如"画出 sin(x) 在 [-2pi, 2pi] 的图像"
2. **要求分步解答**：如"请分步解释如何求这个极限"
3. **要求可视化**：如"用动画演示泰勒展开的逼近过程"
4. **要求对比**：如"对比一下换元法和分部积分法的适用场景"
5. **做练习题**：如"给我出一道关于特征值的测验题"
6. **使用抽认卡**：如"把常用求导公式做成抽认卡帮我记忆"
7. **查看概念图**：如"给我展示微积分的知识概念图"

### 8.2 图片识别

- 支持识别手写和印刷的数学题目
- 图片中的公式会自动转换为 LaTeX 格式
- 识别结果会展示在对话中，可继续追问

### 8.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| Enter | 发送消息 |
| Shift+Enter | 换行 |
| ESC | 退出全屏 |
| 右键 | 弹出收藏/复制菜单 |

### 8.4 设置导入导出

在设置页的"数据管理"区域：
- **导出设置信息**：输入密码加密导出 API 配置等信息为 `.enc` 文件
- **导入设置信息**：粘贴密文或上传 `.enc` 文件，输入密码恢复配置
- **导出聊天记录**：导出所有会话数据为 JSON 文件
- **清空数据**：清理聊天记录或所有信息
