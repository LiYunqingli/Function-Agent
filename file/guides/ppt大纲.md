## PPT 设计规范

### 颜色
- **主色**：钢蓝 `#7e9cb0`（项目暗色主题强调色）
- **辅色**：深灰 `#1c1c1c`、中灰 `#888888`、浅灰 `#e0e0e0`
- **点缀色**：成功绿 `#2e7d32`、错误红 `#c62828`、警告橙 `#ed6c02`
- **背景**：深色系（`#111` → `#1c1c1c` 渐变）

### 字体
- **标题**：思源黑体 / Noto Sans SC Bold，36–48pt
- **正文**：思源黑体 Regular，18–24pt
- **代码 / 数据**：JetBrains Mono（项目自带字体）

### 排版
- 单页文字不超过 6 行
- 多用图标、流程图、对比表，避免大段文字
- 关键数字用大号字（60pt+）

### 配图建议
- **P3** / **P9**：用真实组件截图（最好有交互时的状态）
- **P6** / **P8**：用架构图（draw.io / Excalidraw 出图）
- **P10**：设置弹窗截图

### 动画建议
- P2 / P17：纯文字淡入
- P8：循环图分步绘制（突出 while 循环）
- P13 / P14：左右栏先后出现（讲故事节奏）
