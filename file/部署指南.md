# Function-Agent 部署指南

---

## 1. 部署方式

Function-Agent 是纯前端应用，所有依赖库已本地化存放在 `lib/` 目录，部署方式非常灵活。以下按推荐程度排列。

---

## 2. 方式一：静态文件托管（推荐）

### 2.1 适用场景

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages
- 任何支持静态文件的 Web 服务器

### 2.2 部署步骤

1. **将整个项目目录上传到托管平台**
2. **确保 `index.html` 在根目录**
3. **无需构建步骤**

### 2.3 平台示例

#### GitHub Pages

```bash
# 1. 创建仓库并推送代码
git init
git add .
git commit -m "init"
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main

# 2. 在仓库 Settings → Pages 中选择分支和目录
#    Branch: main, Folder: / (root)
```

#### Vercel

```bash
npm i -g vercel
cd html
vercel
# 按提示配置（无需构建命令，输出目录为 .）
```

#### Netlify

```bash
# 登录 Netlify 后台，拖拽项目目录到部署区域
# 或连接 Git 仓库，设置：
#   Build command: (留空)
#   Publish directory: .
```

## 3. 方式二：Nginx / Apache 部署

### 3.1 Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /path/to/html;
    index index.html;

    # 缓存静态资源
    location ~* \.(css|js|png|jpg|jpeg|gif|ico|svg|woff2|ttf)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    location / {
        try_files $uri $uri/ /index.html;
    }

    gzip on;
    gzip_types text/css application/javascript application/json;
}
```

### 3.2 Apache 配置

```apache
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /path/to/html

    <Directory /path/to/html>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
        FallbackResource /index.html
    </Directory>

    <FilesMatch "\.(css|js|png|jpg|jpeg|gif|ico|svg|woff2|ttf)$">
        Header set Cache-Control "max-age=2592000, public"
    </FilesMatch>
</VirtualHost>
```

## 4. 方式三：本地直接打开

### 4.1 注意事项

- **推荐**：通过本地 HTTP 服务器打开
- **不推荐**：直接双击 `index.html`（`file://` 协议）
  - ES Modules 在 `file://` 下可能被浏览器安全策略阻止
- **亮点**：所有依赖已在 `lib/` 目录，无需网络，开箱即用

### 4.2 快速启动本地服务器

```bash
# Python 3
cd html
python -m http.server 8080
# 访问 http://localhost:8080

# Node.js（npx）
cd html
npx serve .
# 访问 http://localhost:3000

# PHP
cd html
php -S localhost:8080
```

| 库 | 版本 | 目录 | 用途 |

## 7. 安全注意事项

### 7.1 API Key 安全

- API Key 存储在 **localStorage** 中，可被同源 JavaScript 读取
- 支持加密导出设置信息（`.enc` 文件），方便在不同设备间迁移
- **生产环境建议**：通过后端代理 API 请求，避免 Key 暴露在前端

### 7.2 设置导入导出安全

- 导出使用 AES 加密，需设置密码
- 导入需提供导出时设置的密码
- 密文支持粘贴或 `.enc` 文件上传

### 7.3 数据隐私

- 所有数据存储在用户浏览器的 localStorage 中
- 不向任何第三方服务发送数据（除用户配置的 AI API）
- 清除浏览器数据会删除所有会话历史和设置

## 8. 性能优化建议

### 8.1 已实施的优化

- 所有依赖库本地化（`lib/` 目录），零 CDN 依赖，加载更快
- 数学组件**按需动态导入**（`import()`），不阻塞首屏
- 已加载组件渲染器**缓存复用**（`componentRenderers`），后续同步渲染
- Store 状态更新通过**防抖 500ms** 减少 localStorage 写入
- CSS 变量实现主题切换，无需重绘 DOM
- Plotly.js 通过 `<script>` 标签加载，利用浏览器缓存

### 8.2 可选优化

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 资源预加载 | `<link rel="preload">` 预加载关键 JS | 减少首次交互延迟 |
| Service Worker | 注册 SW 缓存所有本地资源 | 离线可用 |
| Plotly 按需引入 | 仅引入 2D 或 3D 模块 | 减小 bundle 体积（当前使用完整版） |
| 压缩 | Gzip/Brotli 压缩 HTML/CSS/JS | 减小传输体积 |
| 字体子集化 | 仅包含常用字符 | 减小字体文件体积 |
