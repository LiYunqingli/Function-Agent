# Function-Agent 部署指南

---

## 1. 部署方式

Function-Agent 是纯前端应用，部署方式非常灵活。以下按推荐程度排列。

---

## 2. 方式一：静态文件托管（推荐）

### 2.1 适用场景

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages
- 任何支持静态文件的 Web 服务器

### 2.2 部署步骤

1. **将整个 `html/` 目录上传到托管平台**
2. **确保 `index.html` 在根目录**
3. **无需构建步骤**

### 2.3 平台示例

#### GitHub Pages

```bash
# 1. 创建仓库并推送代码
git init
git add .
git commit -m "init"
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main

# 2. 在仓库 Settings → Pages 中选择分支和目录
#    Branch: main
#    Folder: / (root)
```

#### Vercel

```bash
# 1. 安装 Vercel CLI
npm i -g vercel

# 2. 在项目根目录执行
cd html
vercel

# 3. 按提示配置（无需构建命令，输出目录为 .）
```

#### Netlify

```bash
# 1. 登录 Netlify 后台
# 2. 拖拽 html/ 目录到部署区域
# 3. 或连接 Git 仓库，设置：
#    Build command: (留空)
#    Publish directory: .
```

## 3. 方式二：Nginx / Apache 部署

### 3.1 Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /path/to/html;
    index index.html;

    # 缓存静态资源
    location ~* \.(css|js|png|jpg|jpeg|gif|ico|svg|woff2)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # SPA 回退（虽然本项目不需要路由）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 启用 gzip
    gzip on;
    gzip_types text/css application/javascript application/json;
}
```

### 3.2 Apache 配置

```apache
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /path/to/html

    <Directory /path/to/html>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted

        # SPA 回退
        FallbackResource /index.html
    </Directory>

    # 缓存静态资源
    <FilesMatch "\.(css|js|png|jpg|jpeg|gif|ico|svg|woff2)$">
        Header set Cache-Control "max-age=2592000, public"
    </FilesMatch>
</VirtualHost>
```

## 4. 方式三：本地直接打开

### 4.1 注意事项

- **推荐**：通过本地 HTTP 服务器打开
- **不推荐**：直接双击 `index.html`（`file://` 协议）
  - ES Modules 在 `file://` 下可能被浏览器安全策略阻止
  - CDN 资源在 `file://` 下的加载可能受限

### 4.2 快速启动本地服务器

```bash
# Python 3
cd html
python -m http.server 8080
# 访问 http://localhost:8080

# Node.js（npx）
cd html
npx serve .
# 访问 http://localhost:3000

# PHP
cd html
php -S localhost:8080
```

## 5. CDN 依赖管理

项目通过 CDN 引入以下外部库，这些是**运行时必需的**：

| 库 | 版本 | 用途 | CDN |
|----|------|------|-----|
| KaTeX | 0.16.11 | LaTeX 公式渲染 | cdn.jsdelivr.net |
| Plotly.js | 2.35.0 | 2D/3D 图表 | cdn.jsdelivr.net |
| math.js | 13.2.2 | 数学表达式求值 | cdn.jsdelivr.net |
| marked.js | 12.0.2 | Markdown 解析 | cdn.jsdelivr.net |
| highlight.js | 11.9.0 | 代码语法高亮 | cdn.jsdelivr.net |

### 5.1 自托管 CDN 资源

如需在离线环境或内网部署，可将 CDN 资源下载到本地：

```bash
mkdir -p lib
cd lib

# 下载所有 CDN 资源
curl -O https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/katex.min.css
curl -O https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/katex.min.js
curl -O https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/contrib/auto-render.min.js
curl -O https://cdn.jsdelivr.net/npm/plotly.js-dist-min@2.35.0/plotly.min.js
curl -O https://cdn.jsdelivr.net/npm/mathjs@13.2.2/lib/browser/math.js
curl -O https://cdn.jsdelivr.net/npm/marked@12.0.2/marked.min.js
curl -O https://cdn.jsdelivr.net/npm/highlight.js@11.9.0/lib/highlight.min.js
```

然后修改 `index.html` 中的 `<link>` 和 `<script>` 标签，将 CDN URL 替换为本地路径。

### 5.2 CDN 可用性检查

部署后应验证所有 CDN 资源可正常加载。在浏览器控制台检查：

```javascript
// 检查关键全局变量
console.log(window.Plotly);   // Plotly 对象
console.log(window.katex);    // KaTeX 对象
console.log(window.math);     // math.js 对象
console.log(window.marked);   // marked 对象
console.log(window.hljs);     // highlight.js 对象
```

## 6. 浏览器兼容性

| 浏览器 | 最低版本 | 说明 |
|--------|----------|------|
| Chrome | 90+ | 完全支持 |
| Firefox | 90+ | 完全支持 |
| Edge | 90+ | 完全支持 |
| Safari | 15+ | 需要 ES Modules + ResizeObserver |
| iOS Safari | 15+ | 需要响应式布局适配 |
| Android Chrome | 90+ | 需要响应式布局适配 |

**关键 API 依赖：**
- ES Modules（`import` / `export`）
- ResizeObserver
- IntersectionObserver
- CSS Custom Properties
- CSS Flexbox / Grid
- Web Workers（未使用，但可扩展）
- AbortController
- fetch API + ReadableStream（SSE）

## 7. 安全注意事项

### 7.1 API Key 安全

- API Key 存储在 **localStorage** 中，**不是** cookie 或 HTTP-only 存储
- 这意味着 API Key 可被同源 JavaScript 读取
- **生产环境建议**：通过后端代理 API 请求，避免 Key 暴露在前端

### 7.2 内容安全

- 用户输入通过 marked.js 渲染为 HTML（已做基本 sanitize）
- KaTeX 渲染数学公式
- 无后端服务，不存在服务器端安全风险

### 7.3 数据隐私

- 所有数据存储在用户浏览器的 localStorage 中
- 不向任何第三方服务发送数据（除用户配置的 AI API）
- 清除浏览器数据会删除所有会话历史

## 8. 性能优化建议

### 8.1 已实施的优化

- 数学组件**按需动态导入**（`import()`），不阻塞首屏
- Plotly.js 通过 CDN 加载，利用浏览器缓存
- Store 状态更新通过**防抖 500ms** 减少 localStorage 写入
- CSS 变量实现主题切换，无需重绘 DOM

### 8.2 可选优化

| 优化项 | 方法 | 效果 |
|--------|------|------|
| CDN 加速 | 使用国内 CDN（如 bootcdn、staticfile） | 国内用户加载更快 |
| 资源预加载 | `<link rel="preload">` 预加载关键 JS | 减少首次交互延迟 |
| Service Worker | 注册 SW 缓存 CDN 资源 | 离线可用 |
| Plotly 按需引入 | 仅引入 2D 或 3D 模块 | 减小 bundle 体积 |
| 压缩 | Gzip/Brotli 压缩 HTML/CSS/JS | 减小传输体积 |
