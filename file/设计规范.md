# Function-Agent 设计规范

本文档定义了项目的视觉设计规范，包括颜色体系、排版、间距、动效和组件样式标准。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **学术专业** | 视觉风格偏向学术/教育工具，不过度娱乐化 |
| **信息密度适中** | 在桌面端展示足够信息，在移动端保持可读性 |
| **暗色优先** | 深色模式不是事后补充，而是与亮色同等级设计 |
| **渐进增强** | 核心功能无 JS 也能显示基本结构（虽然不可交互） |
| **一致性** | 所有组件遵循统一的间距、颜色、字体变量 |

### 2.2 暗色主题

**核心设计理念：黑灰白配色，主题色为微钢蓝调**

| 变量 | 亮色 | 暗色 | 说明 |
|------|------|------|------|
| `--color-bg-primary` | `#ffffff` | `#111111` | 最亮背景 |
| `--color-bg-card` | `#ffffff` | `#1c1c1c` | 卡片/弹窗 |
| `--color-bg-secondary` | `#f5f7fa` | `#181818` | 次级背景 |
| `--color-bg-sidebar` | `#f0f2f5` | `#0a0a0a` | 侧边栏（最深） |
| `--color-bg-dialog` | `#ffffff` | `#1c1c1c` | 弹窗 |
| `--color-text-primary` | `#1a1a2e` | `#e0e0e0` | 主要文字 |
| `--color-text-secondary` | `#5f6368` | `#888888` | 次要文字 |
| `--color-accent` | `#1976d2` | `#7e9cb0` | 主题色（钢蓝） |
| `--color-accent-light` | `#e3f2fd` | `rgba(126,156,176,0.15)` | 强调浅色 |
| `--color-border` | `#e0e0e0` | `#2a2a2a` | 边框 |
| `--color-divider` | `#e8eaed` | `#1f1f1f` | 分割线 |
| `--color-success-bg` | `#e8f5e9` | `#1a2e1a` | 成功背景 |
| `--color-error-bg` | `#ffebee` | `#2e1a1a` | 错误背景 |

暗色主题的关键设计决策：
- **背景不是纯黑**，使用 `#111` / `#1c1c1c` 的梯度层次
- **主题色从蓝色降为钢蓝**（`#7e9cb0`），在深色背景上不刺眼
- **功能色保持辨识度**，但背景色适配深色底
- **阴影加深**（alpha 值 0.4~0.7）

## 8. 动效规范

### 8.1 过渡时长

| 变量 | 时长 | 用途 |
|------|------|------|
| `--transition-fast` | `150ms ease` | 按钮 hover、颜色变化 |
| `--transition-normal` | `250ms ease` | 折叠展开、焦点切换 |
| `--transition-slow` | `400ms ease` | 页面级过渡 |

### 8.2 关键动画

**消息入场：**
- 用户消息：从右滑入（`slideInRight 0.3s ease`）
- AI 消息：从左滑入（`slideInLeft 0.3s ease`）
- 工具卡片：渐入（`fadeIn 0.3s ease`）

**全屏动画：**
- 进入：FLIP 动画（`0.38s cubic-bezier(0.22, 0.61, 0.36, 1)`）
- 退出：反向 FLIP（`0.35s cubic-bezier(0.22, 0.61, 0.36, 1)`）
- 使用具体属性 transition（top/left/width/height），避免 `transition: all`

**加载动画：**
- 流式打字：三点弹跳（`dotBounce 1.4s infinite`）
- 骨架屏：微光扫过（`shimmer 1.5s infinite`）
- 组件加载：骨架屏占位 → 异步替换（`math/index.js` 中的 `componentImporters`）

## 9. 组件样式标准

```
用户气泡：
├─ background: var(--color-bg-bubble-user)     # 蓝色
├─ color: var(--color-text-bubble-user)         # 白色
├─ border-radius: var(--radius-lg)              # 16px

AI 气泡：
├─ background: var(--color-bg-bubble-ai)         # 浅灰

├─ border-radius: var(--radius-lg)                # 16px
├─ border-bottom-left-radius: var(--radius-xs)    # 左下角缩小

```

├─ background: var(--color-bg-card)
├─ border: 1px solid var(--color-border)

## 10. 交互状态

### 10.1 焦点系统

```
默认态：.tool-call-card
├─ 图表容器 pointer-events: none（滚轮穿透）
└─ 边框默认色

聚焦态：.tool-call-card.focused（点击 body 区域触发）
├─ 图表容器 pointer-events: auto（可交互）
├─ border-color: var(--color-accent)
└─ box-shadow: 焦点光晕

失焦态：鼠标移出卡片
└─ 自动恢复默认态
```

### 10.2 按钮状态

| 状态 | 样式 |
|------|------|
| 默认 | `background: transparent; border: 1px solid var(--color-border)` |
| Hover | `background: var(--color-bg-hover); border-color: var(--color-accent)` |
| Active | 背景加深 |
| Disabled | `opacity: 0.5; pointer-events: none` |

### 10.3 收藏面板状态

| 状态 | 样式 |
|------|------|
| 关闭 | `transform: translateX(100%)` |
| 打开 | `transform: translateX(0)` + 遮罩层显示 |
| 列表项 Hover | `background: var(--color-bg-hover)` |
| 删除按钮 Hover | `color: var(--color-error)` |
