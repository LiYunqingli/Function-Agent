# Function-Agent 用户帮助文档

---

## 1. 快速开始

### 1.1 打开应用

直接用浏览器打开 `index.html` 文件即可使用，无需安装任何依赖或启动服务。

### 1.2 配置 AI 模型

首次使用需要配置大语言模型 API：

1. 点击右上角 **设置** 按钮（齿轮图标）
2. 填写以下信息：
   - **API URL**：兼容 OpenAI 格式的 API 地址（如 `https://api.openai.com/v1`）
   - **API Key**：你的 API 密钥
   - **模型名称**：如 `gpt-4o`、`gpt-4o-mini`、`glm-4` 等
   - **Temperature**：控制回复创造性（0.0~2.0，默认 0.7）
   - **Max Tokens**：最大输出长度（默认 4096）
3. 点击保存

### 1.3 图片识别（可选）

如需识别数学题目图片，需额外配置多模态模型：
- **Vision API URL / Key / Model**：支持图片识别的模型连接信息
- **Vision System Prompt**：图片识别的提示词（已预填默认值）

## 2. 基本操作

### 2.1 发送消息

- 在底部输入框中输入数学问题
- 按 **Enter** 发送（**Shift+Enter** 换行）
- 点击发送按钮（向右箭头）

### 2.2 上传图片

- 点击输入框左侧的 **图片上传** 按钮
- 选择包含数学题目的图片
- 输入你想问的问题（可选，不输入则自动分析图片内容）
- 发送后系统会先识别图片，再基于识别结果回答

### 2.3 停止生成

在 AI 回复过程中，点击 **停止** 按钮（红色方块）可中断当前生成。

### 2.4 切换主题

点击右上角的 **月亮/太阳** 图标，在三种主题间切换：
- **亮色模式**
- **暗色模式**
- **跟随系统**

## 3. 会话管理

### 3.1 新建会话

- 点击侧边栏顶部的 **新建对话** 按钮
- 或在欢迎页点击 **开始新对话**

### 3.2 切换会话

点击侧边栏中的会话列表即可切换到对应对话。每个会话的历史消息独立保存。

### 3.3 删除会话

将鼠标悬停在侧边栏的会话上，点击出现的 **删除** 按钮（垃圾桶图标）即可删除。

### 3.4 会话命名

首次对话后，系统会自动以你的第一条消息内容（前 30 字）命名会话。

## 4. 工具调用卡片

当 AI 调用工具时，会在对话中显示一个 **工具调用卡片**，包含：

### 4.1 卡片结构

| 区域 | 内容 |
|------|------|
| **Header** | 工具名称 + 状态徽章（执行中/已完成/失败）+ 全屏按钮 |
| **参数折叠区** | 可展开查看发送给工具的完整参数（JSON 格式） |
| **结果区域** | 工具生成的可视化内容（图表/动画/交互组件） |

### 4.2 全屏查看

- 点击 Header 右侧的 **⛶** 按钮进入全屏
- 或 **双击** 卡片进入全屏
- 全屏后：
  - 按 **ESC** 退出
  - 点击 **右上角关闭按钮** 退出
  - 点击 **背景遮罩** 退出

### 4.3 图表交互

- **默认**：鼠标悬浮在图表上时，滚轮事件穿透到页面（正常滚动）
- **点击图表区域** 后激活焦点（边框高亮），此时可：
  - 拖动平移图表
  - 滚轮缩放图表
  - 悬浮查看数据点
- **鼠标移出卡片** 后自动失焦，恢复滚轮穿透

### 4.4 折叠/展开

点击卡片 Header 区域可折叠/展开结果内容，方便管理长对话。

## 5. 支持的数学工具

### 5.1 微积分（11 个）

| 工具 | 功能说明 |
|------|----------|
| plot_function | 绘制函数图像（支持多条曲线、自定义范围和样式） |

| animate_taylor_series | 泰勒级数展开动画（逐步增加阶数观察逼近效果） |
| show_differential | 微分近似图（切线与实际增量的对比） |
| plot_integral_area | 定积分面积可视化（填充积分区域） |
| plot_gradient_field | 梯度向量场（二元函数的梯度方向分布） |
| plot_surface_3d | 三维曲面图（z=f(x,y) 的立体可视化） |
| animate_solid_of_revolution | 旋转体动画（曲线绕轴旋转生成三维形体） |
| show_step_card | 分步解题卡片（逐步展示解题过程） |
| show_knowledge_tip | 知识点提示框（展示公式/定理/概念） |
| control_parameter_slider | 参数滑块（拖动滑块实时调整参数观察变化） |

### 5.2 级数与逼近（3 个）

| 工具 | 功能说明 |
|------|----------|
| plot_polar_curve | 极坐标曲线绘制（r=f(theta)） |

| plot_fourier_series | 傅里叶级数逼近（方波/锯齿波的傅里叶分解） |

### 5.3 线性代数（2 个）

| 工具 | 功能说明 |

### 5.4 概率统计（2 个）

| 工具 | 功能说明 |
|------|----------|

### 5.5 多元微积分（1 个）

| 工具 | 功能说明 |
|------|----------|
| plot_multivariable_integral | 二重积分区域可视化（3D 展示积分区域和体积） |

### 5.6 辅助工具（3 个）

| 工具 | 功能说明 |
|------|----------|
| render_latex | LaTeX 公式渲染（将 LaTeX 代码渲染为数学公式） |

## 6. 使用技巧

### 6.1 如何获得最佳效果

1. **明确描述需求**：如"画出 sin(x) 在 [-2pi, 2pi] 的图像"
2. **要求分步解答**：如"请分步解释如何求这个极限"
3. **要求可视化**：如"用动画演示泰勒展开的逼近过程"
4. **要求对比**：如"对比一下换元法和分部积分法的适用场景"
5. **做练习题**：如"给我出一道关于特征值的练习题"

### 6.2 图片识别

- 支持识别手写和印刷的数学题目
- 图片中的公式会自动转换为 LaTeX 格式
- 识别结果会展示在对话中，可继续追问

### 6.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| Enter | 发送消息 |
| Shift+Enter | 换行 |
| ESC | 退出全屏 |
